## 二、认识 Blueprint 编辑器

双击任何 `BP_` 开头的资产，就会进入 Blueprint 编辑器。

Editor 中最重要的区域：

| 区域 | 用途 |
|---|---|
| Components | 给 Actor 添加网格、灯光、摄像机等组件 |
| My Blueprint | 查看变量、函数、事件和接口 |
| Event Graph | 连接节点，制作逻辑 |
| Details | 修改当前选中物体或节点的属性 |
| Toolbar | Compile、Save、Play、Debug |

Blueprint 中最常见的两种线：

| 线 | 含义 |
|---|---|
| 白色线 | 执行顺序，表示“先做这个，再做那个” |
| 彩色线 | 数据，表示把一个值传给另一个节点 |

每次修改 Blueprint 后，点击左上角 `Compile`。看到绿色对勾后再保存。

# 第一步：创建两个输入动作

## 1. 打开正确目录

在 Content Browser 中找到：

```text
Content/NightLibrarian/Core/
```

如果没有 `Input` 文件夹，在 `Core` 上右键：

```text
New Folder → 输入 Input
```

进入：

```text
Content/NightLibrarian/Core/Input/
```

## 2. 创建 IA_Interact

在空白处右键：

```text
Input → Input Action
```

命名为：

```text
IA_Interact
```

打开 `IA_Interact`，设置：

| 属性 | 值 |
|---|---|
| Value Type | Digital (Bool) |
| Consume Input | 打开 |
| Trigger When Paused | 关闭 |

保存并关闭。

## 3. 创建 IA_Flashlight

重复同样操作，创建：

```text
IA_Flashlight
```

属性保持不变。

## 4. 把按键加入输入映射

打开模板已有的：

```text
Content/Input/IMC_Default
```

在 Mappings 区域点击加号，添加两项：

| Input Action | Key |
|---|---|
| IA_Interact | E |
| IA_Flashlight | F |

保存 `IMC_Default`。

检查：

- `IA_Interact` 必须映射到 E。
- `IA_Flashlight` 必须映射到 F。
- 不要删除模板原来的 Move、Look 和 Jump。

# 第二步：创建交互接口

## 1. 创建 BPI_Interactable

进入：

```text
Content/NightLibrarian/Interaction/
```

右键：

```text
Blueprints → Blueprint Interface
```

命名为：

```text
BPI_Interactable
```

打开它。左侧 My Blueprint 中点击 `Functions` 旁边的加号，创建三个函数。

第一个函数：

```text
CanInteract
```

输出：

```text
Can Interact：Boolean
```

第二个函数：

```text
Interact
```

输入：

```text
Interactor：Actor Object Reference
```

第三个函数：

```text
GetInteractionText
```

输出：

```text
Text：Text
```

编译、保存并关闭。

## 2. 理解这三个函数

可以把接口理解成一份“可交互物体必须遵守的合同”。

- `CanInteract`：现在能不能交互。
- `Interact`：交互时执行什么。
- `GetInteractionText`：屏幕应该显示什么提示。

玩家不需要知道目标到底是门、书还是开关。玩家只调用接口。

```text

```

不要勾选数组。

## 4. 创建 UpdateInteractionTrace 函数

在 My Blueprint 的 Functions 区域点击 `+`，命名为：

```text
UpdateInteractionTrace
```

进入这个函数。

### 第一部分：取得视线起点和方向

在空白处右键，搜索：

```text
Get Actor Eyes View Point
```

连接：

```text
Self → Target
```

它会输出：

```text
Out Location
Out Rotation
```

### 第二部分：计算射线终点

右键搜索：

```text
Get Forward Vector
```

把：

```text
Out Rotation → Get Forward Vector
```

输出得到方向向量。

右键搜索：

```text
Multiply
```

把：

```text
Get Forward Vector → Multiply A
InteractionDistance → Multiply B
```

右键搜索：

```text
Add
```

把：

```text
Out Location → Add A
Multiply → Add B
```

最终得到：

```text
Start = Out Location
End = Out Location + Forward Vector × InteractionDistance
```

### 第三部分：发射射线

右键搜索：

```text
Line Trace By Channel
```

设置：

```text
Start：Out Location
End：Add 的结果
Trace Channel：Visibility
Trace Complex：关闭
Ignore Self：打开
```

从 `Line Trace By Channel` 的 Return Value 拉出：

```text
Branch
```

### 第四部分：处理命中目标

从 `Line Trace By Channel` 输出中的 `Out Hit` 拉出：

```text
Break Hit Result
```

从 Break Hit Result 找到：

```text
Hit Actor
```

搜索：

```text
Does Implement Interface
```

连接：

```text
Object：Hit Actor
Interface：BPI_Interactable
```

将 `Does Implement Interface` 的输出连接到 Branch 的 Condition。

### 第五部分：成功分支

在 Branch 的 True 分支：

```text
Set CurrentInteractable
Value：Hit Actor
```

然后调用：

```text
Get Interaction Text
```

选择：

```text
Get Interaction Text (Message)
```

连接：

```text
Target：Hit Actor
```

输出文字先连接：

```text
Print String
```

这样可以先看到提示文字。

### 第六部分：失败分支

在 Branch 的 False 分支：

```text
Set CurrentInteractable
Value：空引用
```

然后：

```text
Print String
```

输入为空字符串，或者不做任何事情。

完成后：

```text
Compile
Save
```

## 5. 每帧调用检测函数

回到 `BP_FirstPersonCharacter` 的 Event Graph。

找到或创建：

```text
Event Tick
```

从 Event Tick 的白色输出连接：


# 常见问题

## 1. 射线打不到方块

检查：

- Static Mesh 是否有碰撞。
- Collision Preset 是否为 BlockAll。
- Line Trace Channel 是否为 Visibility。
- 方块是否在玩家前方 250 cm 内。
- 射线是否从摄像机或眼睛位置开始。

## 2. 按 E 没有反应

检查：

- `IA_Interact` 是否映射到 E。
- `IMC_Default` 是否包含 `IA_Interact`。
- 角色 BeginPlay 是否添加了 `IMC_Default`。
- `CurrentInteractable` 是否有效。
- 目标是否实现了 `BPI_Interactable`。
- 是否使用 Enhanced Input Action 节点，而不是普通 Keyboard E 节点。

## 3. 显示提示但按 E 不执行

检查 `Interact (Message)` 节点的 Target 是否是：

```text
CurrentInteractable
```

并确认 `Interactor` 输入是：

```text
Self
```

## 4. 提示一直不消失

检查 Failure 分支是否调用：

```text
HidePrompt
```

并确认 CurrentInteractable 被设置为空。

## 5. 门围绕中间旋转

你的组件层级错误。

正确的层级必须是：

```text
DoorPivot
└── DoorMesh
```

旋转的是 DoorPivot，不是 DoorMesh。

## 6. 手电筒跟着角色乱转

检查 Flashlight 是否附加到第一人称摄像机。

不要只附加到 Actor Root。

## 7. Blueprint 无法编译

查看 Compile 后的错误列表：

1. 找出红色错误节点。
2. 检查输入输出引脚类型是否匹配。
3. 检查变量类型是否正确。
4. 检查是否把 Actor Reference 当成 Component 使用。

不要同时修改很多节点后再编译。每完成一小段就 Compile 一次。

# 今天必须理解的概念

## Interface

接口让玩家不需要知道目标具体是什么。只要目标实现接口，就可以交互。

## Line Trace

从玩家眼睛向前发射一条看不见的线。线的第一个命中物就是交互目标。

## Enhanced Input

UE 5 的输入系统。输入动作描述“玩家想做什么”，输入映射上下文描述“哪个按键触发这个动作”。

## Event Tick

每帧调用一次。今天用它更新交互射线。以后如果性能不足，可以改成 Timer，每 0.05 秒检测一次。

## Event BeginPlay

游戏开始时执行一次。今天用它创建交互提示 UI。
